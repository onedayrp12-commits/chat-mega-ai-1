# MeGa AI — مشروع Android + لوحة إدارة + خادم ذكاء اصطناعي

حزمة مصدر مطوّرة لمشروع MeGa AI، بتصميم أسود وذهبي وواجهة عربية. تحتوي على تطبيق Android مبني بـ Expo/React Native، ولوحة إدارة ويب، وخادم API يتصل بمحرك Google Gemini.

## محتويات المشروع
- `mobile/`: تطبيق Android ومحادثة عربية تتصل بالخادم.
- `server/`: خادم API مع موصل Gemini فعلي، وفحص صحة الخدمة، ونقطة إحصائيات محمية برمز إدارة.
- `admin/`: لوحة إدارة أولية للاتصال بالخادم وعرض عدد المحادثات.

## المطلوب قبل أن يعمل الذكاء الاصطناعي
هذه الحزمة لا تتضمن مفاتيح API أو حسابات استضافة أو حساب Expo الخاص بك. لأسباب أمنية لا يمكن تضمين مفاتيح سرية داخل ZIP أو التطبيق.
1. انشر مجلد `server` على استضافة Node.js تدعم HTTPS.
2. أضف متغيرات البيئة الموجودة في `server/.env.example` إلى إعدادات الاستضافة، وضع مفتاح Gemini الخاص بك في `GEMINI_API_KEY`، وأنشئ قيمة سرية طويلة لـ `ADMIN_TOKEN`.
3. انسخ عنوان HTTPS العام للخادم.
4. ضع العنوان في متغير `EXPO_PUBLIC_API_URL` في بيئة بناء Expo قبل إنشاء APK (القالب في `mobile/.env.example`).
5. انشر محتويات `admin/` على استضافة صفحات ثابتة، ثم استخدم عنوان الخادم ورمز الإدارة في لوحة التحكم.

## بناء APK
من مجلد `mobile` بعد ضبط `EXPO_PUBLIC_API_URL`:
```bash
npm install
npx eas-cli login
npx eas-cli build --platform android --profile preview
```
ملف `eas.json` مضبوط لإنتاج APK في ملف preview. يتطلب البناء حساب Expo واتصالاً بالإنترنت، ثم يظهر رابط تنزيل APK بعد اكتمال البناء.

## تشغيل الخادم محلياً
من مجلد `server`:
```bash
npm install
cp .env.example .env
# املأ GEMINI_API_KEY و ADMIN_TOKEN في .env
npm run dev
```

## ملاحظات مهمة
- هذا ZIP يحتوي على سورس المشروع المطوّر، وليس APK جاهزاً؛ لم يتم إنشاء APK لأن البناء يحتاج حساب Expo وربط عنوان الخادم ومفتاح مزود AI.
- لا تضع مفتاح Gemini داخل تطبيق الهاتف أو مستودع GitHub.
- لوحة الإدارة الحالية تعرض إحصائيات تشغيل أساسية فقط. لا تزال إدارة الحسابات والاشتراكات والدفع ورفع الصور والفيديو وقاعدة البيانات الدائمة غير منفذة.
